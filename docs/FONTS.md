# Dashboard numeric display fonts

MCUDesk can show Dashboard tile values in a small set of bundled typefaces.
Only the large numeric value uses these fonts. Channel names, units, status
text, and the rest of the application keep the normal MCUDesk font.

These files are redistributed unmodified under their original SIL Open Font
License 1.1 terms. The full license text for each family is in
`assets/fonts/licenses/`.

| MCUDesk style | Font | Author / project | License | File | Source |
|---|---|---|---|---|---|
| Default | Current MCUDesk UI font | — | — | not bundled | application stylesheet |
| Seven Segment | DSEG7 Classic Regular | keshikan | SIL OFL 1.1 | `assets/fonts/DSEG7Classic-Regular.ttf` | https://github.com/keshikan/DSEG |
| LCD | DSEG7 Classic Italic | keshikan | SIL OFL 1.1 | `assets/fonts/DSEG7Classic-Italic.ttf` | https://github.com/keshikan/DSEG |
| Fourteen Segment | DSEG14 Classic Regular | keshikan | SIL OFL 1.1 | `assets/fonts/DSEG14Classic-Regular.ttf` | https://github.com/keshikan/DSEG |
| Dot Matrix | Matrix Sans Print Regular | The Matrix Sans Project Authors | SIL OFL 1.1 | `assets/fonts/MatrixSansPrint-Regular.ttf` | https://github.com/FriedOrange/MatrixSans |
| Technical Mono | IBM Plex Mono Regular | IBM Corp. / Bold Monday | SIL OFL 1.1 | `assets/fonts/IBMPlexMono-Regular.ttf` | https://github.com/IBM/plex |

Reserved font names required by the OFL:

- DSEG (keshikan)
- Plex (IBM Corp.)

MCUDesk bundles the original files and does not rename or modify the fonts.
